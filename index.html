Why does my computer warn me the first time?

The installers are not yet code-signed, so Windows SmartScreen and macOS Gatekeeper show a one-time caution. On Windows choose More info → Run anyway; on macOS right-click the app → Open. Questions

Is Voltra really free?

Yes. The free version is a full working app: draw diagrams and plans, run the checks, open Trikker files, and print or export to PDF. The free version limits you to 5 circuits and one floor-plan page and adds a watermark to exports. Pro removes those limits.

What is a .trik file?

It's the file Trikker saves. If you've used Trikker, your drawings are .trik files. Voltra opens them so you don't lose your existing work.

Which should I download?

On Windows, the installer is the usual choice; the portable version runs without installing. On a modern Mac (2020 or later) choose Apple Silicon; on an older Mac choose Intel. On Linux, the AppImage runs on any distribution.

Where is my data stored?

On your own computer. Voltra is a desktop app — your drawings and customer details are saved as files on your machine and are never uploaded. Only a subscription, if you buy one, involves our server (just your e-mail and plan).

Why did my computer warn me when I opened it?

Because the app isn't code-signed yet. It's safe to run — see the note in the download section — and you can verify the file against its published SHA-256.

Does it run on my old Windows PC?

If Trikker runs on it, Voltra will too. It's a standard Windows 10/11 desktop app.
